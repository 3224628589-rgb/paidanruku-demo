## 历史记录说明

- 早期 QA 中的 mobile、device、bottom-progress、two-rows 和 approval-prompts 截图属于移动端/设备屏方案，已被当前 PC 规范替代。
- 早期“底部状态卡”等表述不再适用；当前状态入口固定为右侧 Figma 组件。
- 历史图片与 Remotion 成片保留用于演进追溯，不能作为当前实现的验收依据。

## 后续验收规则

1. 新增页面或交互前，先更新业务规格与 UI 规范，再补充此处的验收证据。
2. 任何改动不得恢复移动端设备框、底部横向状态条、多行照片墙或固定五行品批列表。
3. 修改 Figma 进度组件需重新对照 node `134:2688`，并复验点击状态明细、真实增长动效与核准落点动画。
4. 四张状态卡明细字段以[三期状态卡明细页设计与实现交付](../design/progress-card-detail-pages-v2.md)为准；待核准、准入库、已入库按商品卡计数，但准入库/已入库页面必须保留最新稿要求的采购单一级分组。
