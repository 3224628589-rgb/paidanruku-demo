# PC Demo 手工回归清单

## 前置条件

- 使用 `1920 x 1080` 或常见桌面浏览器尺寸。
- 从任务入口开始；不要用旧 `localhost:4173` 缓存页面。
- 本地静态服务默认使用 `http://127.0.0.1:4174/`。

## 任务与拍单

- [ ] 首屏展示历史任务与“新建入库任务”。
- [ ] 新建任务后进入拍单，任务状态为待拍单。
- [ ] 拍照和上传各能新增票据；已拍票据数量正确。
- [ ] 缩略图为横长竖短的单行横向列表，不折成照片墙。
- [ ] 票据缩略图无删除 X；支持逐张勾选、全选/取消全选，删除所选后票据数量与任务列表统计同步。
- [ ] 未拍票据点击验货/核准会得到拦截提示。

## 验货

- [ ] 已拍票据后可进入验货；扫码取景、品批列表和右侧进度同时可见。
- [ ] 模拟识别可连续执行，品批行数随结果增长。
- [ ] 多票据下，同商品不同票据归属可产生独立品批。
- [ ] 每次识别的最后命中项到达列表顶部，已有项平滑下移。
- [ ] 命中卡约 2 秒后恢复，当前追溯码约 1 秒后恢复。
- [ ] 搜索、查看全部追溯码、删除码、破损待采退均可用；任何任务都不生成无商品资料卡或待核准行。
- [ ] 已录入品批支持逐卡勾选、全选/取消全选当前筛选结果；删除所选只移除已选卡片及卡片内追溯码，并同步重算四类进度数量。

## 核准与进度

- [ ] 无扫码时进入核准被拦截；有扫码后先显示匹配加载，再显示三列工作台。
- [ ] 蓝色入库卡、黄色商品卡、三方数据对比按 node `232:5852` 自上而下同宽排列。
- [ ] 蓝卡展示两条入库单数据和随货单命中图；黄卡展示完整商品资料与六张商品图。
- [ ] 核准完毕进入准入库，核准待定保留待核准且切换下一条。
- [ ] 拍单、验货、核准三页均显示“提报异常”、已入库、准入库、待核准、待验货和蓝绿黄粉轨道。
- [ ] `1280×800` 下蓝/黄/对比卡仍同宽上下排列；共享进度组件无重叠或裁切。
- [ ] 三页进度组件结构和几何完全一致：基础宽 `220px`、状态卡 `152×200px`、提报异常 `152×70px`、轨道宽 `50px`。
- [ ] 三页四卡均使用同一组真实动态数量；切换步骤前后数字与轨道比例不变，不存在任务专用固定值。
- [ ] 三页点击“提报异常”均出现“已标记：提报异常”。
- [ ] 点击“留在待核准”后当前队列卡移动到队尾，待核准数量不变，右侧待核准卡和轨道均不发光。
- [ ] 点击“展开全部字段”后对比卡按内容增高，所有字段可读且“收起全部字段”可恢复源稿收起态。
- [ ] 真实数量增加会播放一次充能与卡片弹动；普通切页不播放。
- [ ] 动效结束后无 `charging`、`bucket-impact`、`batch-rush-top` 类残留。

## 三期状态卡明细

- [ ] 待验货按随货单图片一级、OCR 行二级展示；图片头包含页码、图片、供应商、业务单号、销售/发货日期。
- [ ] 待验货支持页码精准、通用名模糊、批准文号精准和“只看未验货”；勾选/全选/删除后二次确认并实时减数。
- [ ] 待核准一卡一行，列表数量与待核准卡、核准队列一致；展示应录/实录追溯码和当前异常项。
- [ ] 待核准异常多选采用并集筛选；单条/批量提交遇未匹配系统单时提示“未匹配系统单据，无法入库”。
- [ ] 准入库按采购单一级、商品二级展示；支持全局、采购单、商品勾选联动，能批量回退待核准。
- [ ] 准入库只提交勾选项；确认文案正确，完成系统行复核、入库草稿与 A/B/C 结果回执。
- [ ] 批次编辑结果同步出现在准入库、入库草稿和已入库列表。
- [ ] 已入库字段同准入库，核准详情除返回外没有编辑、换单、展开或图片点击。
- [ ] `1440 x 900` 与 `1280 x 800` 下无页面级横向滚动，数量、状态与操作列仍在首屏。
- [ ] 验货页绿色“无需核准”对应明细核准状态 `1`，黄色“待核准”对应明细核准状态 `0`，蓝色“已入库”对应入库状态 `1`。
- [ ] 重复识别已入库追溯码时提示“无法录入已入库追溯码”，码数、排序、命中类和四卡进度均不变化。
