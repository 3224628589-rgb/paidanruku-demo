# ADR-0001：以任务入口和 PC 工作台替代设备屏 Demo

- 状态：已接受
- 日期：2026-07-11

## 背景

原型起源于高拍仪/移动端式设备屏，页面有设备外框、纵向空间分配、底部横向状态卡和多行照片墙。随着任务管理、票据累积、验货列表和核准证据增加，该形态无法有效利用桌面端横向空间，也无法承载历史任务入口。

## 决策

1. 首屏改为入库任务列表，任务是一次入库工作的根实体。
2. 任务内部保留拍单、验货、核准三步，步骤条横向呈现并包含返回任务列表。
3. 拍单采用主取景框 + 右侧单列票据；验货采用扫码、品批、进度三列；核准采用队列、详情、进度三列。
4. 入库进度组件固定在工作区右侧，按 Figma node `134:2688` 还原，不再使用底部横向四等分状态卡；进度数字从任务状态计算而非固定样例。
5. 移动端、设备外框和旧的浮动核准气泡不再是当前验收范围。

## 后果

- 优点：任务与历史数据有明确入口；PC 空间服务核心操作；核准可同时看到队列、证据和状态。
- 约束：所有新页面必须适配桌面 grid；状态组件视觉参数不应为业务数据展示随意改动。
- 代价：旧 Remotion 截图和移动端 QA 只保留为历史材料，不能作为新 UI 基线。
