# 入库 Demo UI 设计规范

本规范用于当前 Mac 演示版原型。目标是让拍单、验货、核准三个工作台在 Mac 内置屏幕上完整、紧凑、可读，避免字号和空间分配失控。

## 画布与适配

- 演示优先视口：Mac 内置屏幕浏览器窗口，约 `1200-1512px` 宽、`800-982px` 高。
- 设备外框按视口高度反推宽度：优先完整展示，不外接显示器时不能出现底部进度区被挤出屏幕。
- 页面核心内容优先级：取景/扫描画面、核准蓝卡、对比表、底部进度条优先；标题、说明、装饰和重复边框必须让位。
- 移动端不作为验收目标。

## 字体层级

参考 Ant Design 的层级思路，但为高密度中文工作台收敛为 6 档：

| Token | 字号/行高 | 用途 |
| --- | --- | --- |
| `--font-display` | `24 / 32` | 关键价格、最高强调数字 |
| `--font-title` | `20 / 28` | 顶部步骤、页面主标题、核心提示 |
| `--font-subtitle` | `17 / 24` | 商品名、蓝卡主标题、重要卡片标题 |
| `--font-body` | `14 / 22` | 分区标题、按钮主文案、表格主值 |
| `--font-caption` | `12 / 20` | 字段名、元信息、表格普通值 |
| `--font-micro` | `11 / 16` | 标签、辅助说明、紧凑按钮 |

规则：

- 同一信息层级必须使用同一档字号，不再临时新增 `13px`、`15px`、`18px` 等散值。
- 高密度工作台里，正文默认使用 `14/22`，说明和字段默认使用 `12/20`。
- 只有价格、计数、核心商品名可以加粗放大；辅助说明不能抢主信息面积。
- 字间距保持 `0`。

## 动效

- 数量增加统一使用底部卡片 `bucket-impact` 弹动，耗时约 `1s`，幅度克制。
- 进度条只有真实数量增加时使用 `charging` 充能动效；页面切换和普通重渲染不能触发发光。
- 进度顺序固定为：待验货 / 待核准 / 准入库 / 已入库。
- 待验货、待核准增加时高光向右推进；准入库、已入库增加时高光从左侧推进，表现为进度向左吃入。
- 核准气泡出场和消失都控制在 `0.5s` 内，不能持续漂浮。
- 核准气泡点击后：双气泡同时破裂，小水珠快速消散，目标卡片弹动约 `1s`。
- 核准卡片掉落总耗时小于 `0.5s`，运动节奏先慢后快，落点干脆。
