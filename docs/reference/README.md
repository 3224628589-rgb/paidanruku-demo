# 参考资料

此目录存放外部接口、原始需求和业务样本。它们用于追溯来源，**不直接定义当前 PC 页面**；页面和交互必须以 `product/` 与 `design/` 为准。

| 材料 | 用途 | 使用方式 |
| --- | --- | --- |
| [码上放心接口参考](ma-shang-fang-xin-api.md) | 追溯平台接口与字段 | 生产接入时核对，不把接口字段直接等同为 UI。 |
| `original-requirements/` | 原始 Word 需求 | 仅用于回溯业务背景和未确认规则。 |
| `business-samples/` | 商品匹配 `.xlsx` 样本数据 | 作为业务核对和后续测试夹具候选，不能直接覆盖当前页面规则。 |

当某项参考材料被确认成为当前规则时，应把结论写入 `product/`、`design/` 或 ADR，而不是修改原始文件。
