# 核准页面设计沉淀

## 设计目标

核准页不是普通列表页，而是店员处理异常入库明细的“单条核准工作台”。页面需要让用户一眼知道当前在核哪一条、异常在哪里、下一步应该点哪个决策入口，并且在处理完一条后自然进入下一条。

## 本次自我审视

1. 黑白灰层级
   - 之前左侧“待核准”数字和按钮权重偏高，抢了当前核准明细的注意力。
   - 本次将左侧队列降级为轻量导航，主标题和当前商品保持最强黑色权重，说明信息使用灰色，状态与异常才使用色彩。

2. 色彩纯度
   - 页面主色保持蓝色，代表当前、系统推荐、选择入库。
   - 橙色只用于异常与“先不入库”，避免整页多色抢戏。
   - 白色卡面、浅灰背景、低饱和描边负责承载信息，让页面更安静。

3. 轻拟物与 3D
   - 步骤条和底部决策入口继续使用轻拟物体积感，但减少多层矩形嵌套。
   - “先不入库/选择入库”变成更低、更轻的异形胶囊，图标破形露出，让按钮更像可投递的状态入口。

4. 动效反馈
   - 当前条目归类时，左侧当前行会淡出并缩小，飞行动画带弧线落入目标入口。
   - 目标入口触发果冻弹性反馈，强化“刷完一条，进入下一条”的体感。

## 页面结构原则

- 左侧队列只回答“还有多少、当前是哪条”，不承担详情展示。
- 中间详情只展示当前核准明细，优先展示商品名、规格、数量、采购单与供应商。
- 异常条必须足够显眼，但不做大面积警告色，避免长时间操作时造成视觉疲劳。
- 底部两个决策入口必须比普通按钮更有记忆点，因为它们是这个页面最核心的动作。
- 二级列表继续保留，用于查看“先不入库/选择入库”的归类结果，但不打断主核准流程。

## 后续可继续打磨

- 当前对比表仍然偏表格化，后续可以把异常字段拆成“异常摘要卡 + 三方来源对照”的组合。
- 可以增加单条核准进度，如“第 4/20 条”，但应放在弱信息层，不能抢当前商品标题。
- 可加入手势滑动：向左先不入库、向右选择入库，让刷卡体验更完整。
