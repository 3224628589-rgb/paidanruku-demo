# 拍单页：交互与业务逻辑

## 1. 页面目标

店员把供应商随货同行单变成可用于后续匹配的票据集合。拍单页的第一优先级是看清当前票据和完成拍照；票据管理是紧邻主画面的轻量结果区。

## 2. 进入与离开

| 场景 | 规则 |
| --- | --- |
| 新建任务 | 默认进入拍单，已拍票据为 `0`。 |
| 从历史任务进入 | 恢复任务已有票据和当前步骤。 |
| 进入验货 | 至少有一张票据；否则步骤条提示“请先拍摄或上传随货同行单”。 |
| 返回任务列表 | 保留票据数并回写任务统计。 |

## 3. PC 页面结构

```text
┌──────────────────────────── 横向步骤条：返回任务列表 / 拍单 / 验货 / 核准 ────────────────────────────┐
│                                                                                                      │
│  ┌──────────── 随货同行单高拍仪取景 ────────────┐ ┌─ 已拍票据：单列 ─┐ ┌── 入库进度查询 ──┐ │
│  │ 票据画面 / [从相册上传] / [拍照]             │ │ [票据照片 1]     │ │ 已入库             │ │
│  │                                                │ │ [票据照片 2]     │ │ 准入库             │ │
│  │                                                │ │ [更多票据…]      │ │ 待核准             │ │
│  └────────────────────────────────────────────────┘ └──────────────────┘ │ 待验货 + 轨道      │ │
│                                                                            └──────────────────┘ │
└──────────────────────────────────────────────────────────────────────────────────────────────────────┘
```

### 布局约束

- 取景框占拍单页最多面积；不加设备外框或额外标题条。
- 已拍票据位于取景框右侧，为单列纵向滚动列表；每行只显示一张票据照片。
- 右侧固定为 Figma 进度组件；它不是底部状态条，不能被票据列表挤到页面底部。

## 4. 数据与状态

| 数据 | 当前实现 | 影响 |
| --- | --- | --- |
| `state.photos` | 任务内票据数组，包含 id、标题、图片 | 决定已拍票据数、右侧单列照片和验货进入条件。 |
| 票据标题 | 拍照为“拍摄票据 n”，上传为“相册票据 n” | 用于右侧单列照片辅助识别。 |
| 待验货 | 有票据但对应票据行还未被实物匹配 | 新增票据时可能增加。 |

生产版应为每张票据保留任务 id、原图、OCR 状态、上传时间和 OCR 行；当前 Demo 使用本地图片模拟。

## 5. 交互规则

| 操作 | 前置条件 | 系统行为 | 反馈 |
| --- | --- | --- | --- |
| 拍照 | 无 | 锁页完成 OCR、随货单重匹配和智能核准，再新增“拍摄票据” | `识别成功！`；失败为 `识别失败，请重新拍照或上传`。 |
| 从相册上传 | PNG/JPG 且不超过 10MB | 校验文件后执行与拍照相同的 OCR 链路 | 类型、大小或识别失败均不新增票据。 |
| 勾选票据 | 票据存在 | 勾选框记录待删除图片；缩略图右上角不再提供单张删除 X | 选中缩略图显示蓝色选中边框，标题栏显示已选数量。 |
| 全选 / 取消全选 | 票据存在 | 一次选中或取消当前全部票据图片 | 全选框同步选中、部分选中和未选状态。 |
| 删除所选 | 至少勾选一张票据 | 指定文案二次确认；确认后锁页删除、释放关联、匹配下一候选并重新核准 | 更新票据数和四状态投影；删除后清空选择。 |
| 点击验货 | 有票据 | 切换到验货 | 步骤条更新。 |
| 点击核准 | 有票据但无扫码 | 不进入核准，切到验货 | “请先完成验货扫码”。 |

## 6. 动效与异常

- 新票据照片加入时使用轻量出现反馈；不得改变右侧单列布局或推挤主取景框。
- 新增票据仅在待验货的真实数量增长时触发右侧进度动效；普通重新渲染不播放。
- 空票据区显示“票据照片会显示在这里”，不展示营销或流程解释。

## 7. 验收

- [ ] 新建任务进入拍单，已拍票据为 `0`。
- [ ] 拍照、上传均能在右侧单列新增一张票据照片，数量正确。
- [ ] 多张票据保持单列纵向滚动，每行一张，不出现照片墙。
- [ ] 缩略图右上角没有删除 X；逐张勾选、全选、取消全选均正确。
- [ ] “删除所选”只删除已勾选图片，并同步票据数量、任务统计和待验货状态。
- [ ] 删除前显示“删除随货单图片后将重新匹配随货单并智能核准，请注意待核准数量的变化。”。
- [ ] 无票据不能进入验货/核准；有票据可进入验货。
- [ ] 右侧进度组件在拍单页保持可见，新增票据的真实状态增长有且仅有一次动效。
