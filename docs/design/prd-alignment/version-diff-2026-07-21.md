## 3. 本轮结构结论

```text
进度卡详情
├─ 待验货：随货单图片（一级）
│  └─ OCR 随货单明细行（二级）→ 筛选 / 勾选 / 删除
├─ 待核准：验货商品卡平铺
│  └─ 异常筛选 / 查看核准详情 / 勾选提交准入库
├─ 准入库：采购单（一级）
│  └─ 验货商品卡（二级）→ 查看详情 / 勾选回退 / 勾选入库
└─ 已入库：与准入库相同字段结构
   └─ 核准详情只读，仅能返回
```

## 4. 明确保留的既有后续口径

新稿多处把状态卡统计写成“随货单明细行数量”，但状态枚举实际来自验货明细，且用户已明确要求一张商品卡计为一、待核准需展开为逐件行。因此本轮继续保持：

- 待验货按未发生实物命中的 OCR 随货单明细行计数；不使用包装数量。
- 待核准、准入库、已入库按可独立核准的商品卡计数；Demo 中一件一码、一行计一。
- 切换拍单、验货、核准步骤不重置共享进度数据。
