# 页面结构与滚动契约

## 2026-07-21 新增状态明细结构

```text
待验货
┌ 返回 │ 标题/行数 │ 页码 │ 通用名 │ 批准文号 │ 只看未验货 │ 全选 │ 删除 ┐
├ 图片一级：页码 / 随货单图 / 供应商 / 业务单号 / 销售日期 / 发货日期 ┤
│  ├ OCR 行：行序号 / 商品 / 规格 / 准字 / 剂型 / 厂家 / 批次 / 数量 / 单价 │
│  └ OCR 行……                                                                  │
└──────────────────────────────────────────────────────────────────────────────┘

待核准
┌ 返回 │ 标题/行数 │ 商品筛选 │ 准字筛选 │ 异常项多选 │ 全选 │ 提交勾选 ┐
├ 选择 │ 供应商 │ 药品/规格 │ 准字/剂型/厂家 │ 批次 │ 应录/实录码 │ 异常 │ 详情 ┤
└───────────────────────────────────────────────────────────────────────────────┘

准入库 / 已入库
┌ 返回 │ 标题/行数 │ 全选 │ [回退勾选] [提交勾选入库] ┐
├ 采购单一级：平台 / 采购单 / 状态 / 供应商 / 平台单号 / 运单号 ┤
│  ├ 商品二级：名称 / 规格 / 准字 / 条码 / 厂家 / 最终入库批次 / 数量 / 单价 │
│  └ 商品二级……                                                                 │
└───────────────────────────────────────────────────────────────────────────────┘
```

已入库详情为只读态：页面内不出现除“返回”之外的按钮或可点击证据元素。

## 1. 任务列表

```text
┌──────────────────────────────────────────────────────────────────────┐
│ 掌店易智能入库 / 入库任务                              [新建任务] │
├──────────────────────────────────────────────────────────────────────┤
│ 历史任务 + 筛选                                                     │
├────────┬────────┬────────┬────┬────┬────┬────┬─────────────┬──────┤
│任务号  │创建日期│操作日期│待验│待核│准入│已入│采购单/供应商│ 进入 │
├────────┴────────┴────────┴────┴────┴────┴────┴─────────────┴──────┤
│ 任务行列表（仅本区纵向滚动）                                       │
└──────────────────────────────────────────────────────────────────────┘
```

创建日期与最近操作日期只显示 `YYYY-MM-DD`；任务行卡片数来自该任务当前状态投影。

## 2. 拍单

```text
┌────步骤────┬────────────────主取景框────────────────┬──票据列表──┬──共享进度──┐
│返回任务列表│                                                  │全选/删除   │提报异常   │
│拍单 active │ 高拍仪画面                                       │图片页 1    │已入库     │
│验货        │ 上传入口 + 拍照按钮                              │图片页 2    │准入库     │
│核准        │                                                  │纵向滚动    │待核准     │
│            │                                                  │            │待验货+轨道│
└────────────┴──────────────────────────────────────────┴────────────┴───────────┘
```

- 票据顺序：图片页码升序；同页按上传时间；无页码置后。
- OCR、删票后的重匹配和智能核准期间页面锁定。

## 3. 验货

```text
┌────步骤────┬────────扫描取景框────────┬──────已录入品批──────┬──共享进度──┐
│拍单        │                           │搜索 / 码数 / 全选删除│提报异常   │
│验货 active │ 0.5 秒分组识别 + 等待态   │商品批次卡纵向滚动    │四状态卡   │
│核准        │ 命中卡冲到顶部            │状态色/实录码/破损开关 │四色轨道   │
└────────────┴───────────────────────────┴──────────────────────┴───────────┘
```

- 绿色：无需核准；黄色：待核准；蓝色：已入库。
- 搜索字段：通用名、批准文号、批号、追溯码。
- 卡片删除按选择集合执行；追溯码编辑不能删掉最后一条码。

## 4. 核准

```text
┌────步骤────┬─待核准队列─┬────────────证据详情（纵向滚动）────────────┬──共享进度──┐
│拍单        │数量+搜索    │蓝：实物/系统单/随货单命中行               │提报异常   │
│验货        │商品 X1      │黄：O2O 商品资料与 6 图                    │已入库     │
│核准 active │仅当前行操作 │三方对比：异常展开，一致字段默认收起        │准入库     │
│            │其余队列滚动 │系统单候选 / 随货单候选 / 批次 / 追溯码弹窗│待核准     │
│            │             │                                             │待验货+轨道│
└────────────┴─────────────┴─────────────────────────────────────────────┴───────────┘
```

- “放入准入库”：当前卡离开队列，准入库加 1。
- “留在待核准”：待核准数量不变，当前卡移动到队尾，不触发右侧发光。
- 新待核准卡按创建时间倒序进入队首；已明确留待的卡固定排在未处理卡之后。

## 5. 核准辅助弹窗（Figma `363:90`）

```text
编辑批次                  编辑追溯码
┌──────────────────┐      ┌────────────────────────┐
│ 标题            ×│      │ 标题                  ×│
├──────────────────┤      ├────────────────────────┤
│ 实物批次一键填入  │      │ 20 位追溯码输入   [清空]│
│ 随货单批次一键填入│      │ 实录追溯码（实录/应录） │
│ 采购单批次一键填入│      │ 蓝色应录 / 黄色非应录码 │
│ 批号/效期/生产日期│      │                        │
│      [保存整行]   │      │      [保存整行]         │
└──────────────────┘      └────────────────────────┘

换采购单 / 换随货单
┌──────────────────────────────────────┐
│ 采购单（或随货单）商品匹配错了，换一个 ×│
├──────────────────────────────────────┤
│ 单据信息  [筛选输入；Enter 查询]       │
│ 商品信息  [筛选输入；Enter 查询]       │
│ 候选卡：票据图/单号、商品、批号、得分   │
│ 候选卡……                    [确定]     │
└──────────────────────────────────────┘
```

- 弹窗居中覆盖核准页，不改变三页共享进度数据。
- 候选列表是弹窗内部滚动区；标题、筛选和底部“确定”保持可见。
- 1440×900 与 1280×800 使用同一结构，只按可用视口约束宽高。
