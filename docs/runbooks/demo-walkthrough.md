# 掌店易智能入库 PC Demo 说明

## 演示入口

本地预览地址：`http://127.0.0.1:4174/`。

首屏是**入库任务列表**，不是三步工作台。选择历史任务或点击“新建入库任务”后，进入任务内的拍单、验货、核准流程。

## 推荐演示路径

1. 在入口页点击“新建入库任务”。
2. 在拍单页点击拍照或上传，确认已拍票据在主取景框右侧以单列、每行一张出现，待验货卡与轨道随之增长。
3. 点击步骤条中的“验货”。
4. 点击“模拟识别”，观察本次命中品批冲到右侧列表顶部，其他卡片被平滑挤下。
5. 连续点击模拟识别，确认多个票据的品批持续累积，而不是固定为五行。
6. 点击“核准”，等待智能匹配加载完成。
7. 在左侧队列切换异常商品；在中部查看采购单、随货单、实物和美团商品信息的核对结果。
8. 点击当前核准队列项的绿勾或黄问号，确认卡片飞入右侧的准入库/待核准落点，队列切换和状态明细更新。
9. 点击右侧“已入库 / 准入库 / 待核准 / 待验货”任一进度卡，查看对应页内明细。

## 关键体验

- **拍单**：高拍仪取景是视觉主体；票据照片固定在右侧单列，每行一张。
- **验货**：品批按“票据 + 商品批次”聚合；同一批次追加追溯码，新的命中始终置顶。
- **核准**：只在此处处理差异，绿勾/黄问号只出现在当前队列项；验货页仅提示“无需核准 / 待核准”。
- **进度**：右侧 Figma 进度组件是状态入口。仅在实际数量增加时播放充能发光与卡片弹动；普通切页不会播放。

## 演示数据边界

当前为前端演示数据：拍照、上传、扫码、匹配、替换候选和入库状态均在浏览器内模拟，不调用真实高拍仪、OCR、追溯平台或库存接口。
