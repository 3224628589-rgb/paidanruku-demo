# 本地开发与预览

## 启动

项目是静态页面，不需要安装依赖。仓库根目录执行：

```bash
python3 -m http.server 4174
```

访问 `http://127.0.0.1:4174/`。若端口被占用，使用一个空闲端口，并在演示说明中明确最新地址。

## 开发流程

1. 修改页面结构、脚本或样式。
2. 修改 `styles.css` 或 `app.js` 后，更新 `index.html` 对应资源的版本参数，避免静态托管缓存继续加载旧文件。
3. 刷新浏览器，从任务入口走完受影响的路径。
4. 运行：

```bash
node --check app.js
git diff --check
```

5. 按 [PC Demo 手工回归清单](../qa/test-checklist.md) 复验，必要时更新 [当前 PC QA](../qa/current-pc.md)。

## 常见问题

| 现象 | 排查 |
| --- | --- |
| 页面还是旧布局 | 检查地址是否为当前端口，确认 `index.html` 的 CSS/JS 版本参数已更新，然后强制刷新。 |
| 任务数据不符合预期 | 返回任务入口重新进入任务；新建任务会从空状态开始。 |
| 进度动效未出现 | 只在真实数量增加时播放，切换步骤不应播放。 |
| 核准页空白 | 先完成拍单和验货；无扫码进入核准会被引导回验货。 |
